# Administration RH V3.1

Ajout de l’onglet **Demandes RH** permettant de configurer le délai d’auto-validation utilisé par Cockpit RH V6.58.

Table : `PARAM_DEMANDES_RH`
- `Cle` Text
- `Valeur` Text
- `Actif` Bool
- `Commentaire` Text

Clé : `DELAI_AUTO_VALIDATION_SECONDES`

Le champ accepte une valeur entre 0 et 86400 secondes.
